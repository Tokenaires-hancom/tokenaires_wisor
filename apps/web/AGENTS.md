# AGENTS.md — apps/web

**규칙 본문은 [`CLAUDE.md`](CLAUDE.md)에 있습니다. 화면 코드를 건드리기 전에 읽으세요.**
저장소 전체 규칙은 [루트 `AGENTS.md`](../../AGENTS.md)와 [루트 `CLAUDE.md`](../../CLAUDE.md)에 있습니다.

아래는 어겼을 때 조용히 깨지는 것들만 다시 적은 것입니다.

## 경계

- **`lib/scores.ts`는 서버 전용입니다.** 클라이언트 컴포넌트에서 import하면 `scores.json` 전체가 브라우저 번들에 실립니다. 타입과 라벨은 `lib/scores.types.ts`에서 가져오고, 데이터는 서버 컴포넌트에서 props로 내려보냅니다.
- **저장은 `lib/store.ts`만 거칩니다.** 컴포넌트에서 `localStorage`를 직접 부르지 않습니다. 함수는 전부 `Promise`를 돌려주는데, Supabase로 교체할 때 시그니처를 그대로 두기 위해서입니다. 동기로 되돌리지 마세요.
- **차트 분석기에 종목명과 티커를 넘기지 않습니다.**

## 색

하드코딩한 hex를 새로 넣지 않습니다. 색은 `globals.css`의 CSS 변수만 씁니다.
현재 팔레트와 각 토큰의 역할은 `CLAUDE.md`의 「디자인 토큰」 절에 있습니다.

두 가지만 기억하세요.

- **골드 위의 글자는 16px 이상, 굵기 700 이상입니다.** 골드는 밝아서 작은 글씨가 읽히지 않습니다.
- **상태를 색만으로 구분하지 않습니다.** 기준 막대가 그 예입니다 — 충족은 단색 채움, 미충족은 빗금, 미판정은 점선 테두리라 흑백으로 봐도 갈립니다. 이 구분을 "정리"하지 마세요.

## 확인

```bash
npm test        # node --test. 새 테스트는 content/ 또는 lib/ 아래 *.test.ts 여야 실행됩니다
npm run build
```

화면을 바꿨으면 개발 서버에서 실제로 봅니다. 계산된 스타일을 재는 것까지 해야
"골드가 들어갔다"가 아니라 "골드가 `rgb(255, 160, 0)`으로 들어갔다"를 말할 수 있습니다.

`node_modules`가 없으면 `npm install`부터 합니다. 새 패키지는 먼저 물어보세요.
