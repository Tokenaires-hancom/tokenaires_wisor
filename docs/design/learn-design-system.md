# Wisor 배우기 디자인 시스템

> 기준 화면: `/learn` → `/learn/masters/[slug]` → `/learn/masters/[slug]/[chapter]`
> 상태: 구현 기준 정본 · 2026-08-12
> 목적: 다른 메뉴를 설계할 때 Wisor의 학습 경험과 시각적 언어를 같은 원칙으로 확장한다.

## 1. 이 화면이 해야 하는 일

Wisor는 **기업을 고르는 기준과 가격을 관찰하는 방법을 가르치는 투자 학습 서비스**다.
따라서 배우기 화면은 정보를 많이 보여주는 금융 대시보드가 아니라, 사용자가 다음 행동을
망설이지 않게 하는 학습 경로여야 한다.

1. 워런 버핏에서 조지 소로스까지 이어지는 대가 학습 순서를 파악한다.
2. 현재 위치와 다음 한 걸음을 즉시 파악한다.
3. 짧게 읽고, 한 문항씩 답하고, 다음 단계로 간다.

시각적 키워드는 **깨끗한 흰 바탕, 금색의 전진, 와인색의 현재 위치, 캐릭터의 안내**다.
듀오링고의 게임적 명료함은 가져오되, 투자 교육 서비스이므로 장난감 같은 장식은 늘리지
않는다. 숫자·노드·진행 막대는 모두 실제 학습 순서와 진도를 설명해야 한다.

## 2. 전체 원칙

| 원칙 | 적용 방법 |
| --- | --- |
| 한 화면에 한 행동 | 카드 선택, 현재 챕터 시작, 한 문항 답하기 중 하나만 금색 주 행동으로 둔다. |
| 흰 공간은 위계다 | 배경을 누렇게 채우지 않는다. 여백으로 제목, 학습 경로, 본문을 분리한다. |
| 금색은 전진 상태 | 완료, 시작, 계속, 선택된 대가에만 쓴다. 장식용 남용 금지. |
| 와인색은 현재·정답·강조 | 현재 노드 테두리, 활성 메뉴, 진행 막대, 문장 핵심에 쓴다. |
| 캐릭터는 안내자 | 캐릭터는 내용과 행동을 향해야 하며, 글 또는 문항 위에 겹치지 않는다. |
| 움직임은 신호만 | 다음 단계 CTA의 작은 상하 움직임 등 행동을 부르는 곳에만 사용한다. |

## 3. 기본 토큰

### 3.1 색상

| 이름 | 값 | 용도 |
| --- | --- | --- |
| Paper / Surface | `#FFFFFF` | 전체 배경, 카드, 배너 내부의 흰 요소 |
| Surface sunk | `#F7F7F7` | 약한 비활성 면 |
| Ink | `#4B4B4B` | 제목, 본문, 기본 아이콘 |
| Ink soft | `#777777` | 보조 본문 |
| Ink faint | `#AFAFAF` | eyebrow, 메타, 미완료 숫자 |
| Line | `#E5E5E5` | 기본 구분선, 카드 테두리 |
| Line strong | `#CFCFCF` | 비활성 그림자, 강한 경계 |
| Gold | `#FFA000` | 주 행동, 완료 노드, 유닛 배너, 선택 대가 |
| Gold deep | `#C67B00` | 금색 버튼·노드의 4~5px 바닥 그림자 |
| Gold soft / line | `#FFF4E0` / `#FFD08A` | 골드의 약한 배경·테두리 |
| Wine | `#C2183C` | 현재 상태, 활성 탭, 정답·강조 |
| Wine deep | `#92102C` | 워드마크, 더 진한 와인 텍스트 |
| Wine soft / line | `#FCE9ED` / `#EFA9B7` | 현재 상태의 배경·보조 테두리 |
| Ochre | `#8A5A17` | 오답 또는 주의성 정보 |
| Ochre soft / line | `#F5ECDD` / `#DCC49A` | 오답 배경·테두리 |

색은 의미를 중복해 쓴다. 예를 들어 현재 단계는 와인색만 쓰지 않고 **굵은 테두리와
높은 진행 막대**를 함께 사용하며, 완료 단계는 **체크 아이콘과 금색 면**을 함께 쓴다.
Gold 위의 흰 글자는 대비가 낮으므로 16px 이상·700 이상인 주 행동 텍스트에만 사용한다.
작은 설명문·보조 정보는 Gold 면 위에 올리지 않는다.

### 3.2 타이포그래피

- 기본 서체: `Pretendard Variable`, `Pretendard`, 시스템 산세리프 순서.
- serif, 금융 신문체, 장식용 display 폰트를 추가하지 않는다.
- 기본 본문: 16px, line-height 1.7.
- 본문 단락: 1.03rem, line-height 1.9, 최대 40em. 본문만 억지로 720px까지
  늘리지 않는다. 넓은 문항 칼럼 안에서도 문단은 읽기 폭을 지킨다.
- 페이지 핵심 제목(`.thesis`): `clamp(1.9rem, 4.4vw, 3rem)`, 800, line-height 1.35.
- 챕터 제목: `clamp(1.8rem, 4vw, 2.5rem)`, 800, line-height 1.3.
- 카드 이름: 1.12rem, 800. 유닛 배너 이름: 1.35rem, 800.
- 일반 버튼: 1rem, 700. 보조 도구: 0.9rem, 750.
- eyebrow: 0.68rem, 자간 `0.16em`, 흐린 회색. 구조 라벨에만 사용한다.
- 한글 제목과 카드명에는 `word-break: keep-all`을 적용해 단어 중간 줄바꿈을 막는다.

### 3.3 모서리·그림자·간격 단위

- 기본 radius: 12px. 정보 카드, 버튼, 배너 모두 같은 값으로 묶는다.
- 원형은 노드·초상화·화살표에만 쓴다. 임의의 pill 남용 금지.
- Wisor의 입체감은 흐린 큰 그림자보다 **아래쪽 3~5px 단색 그림자**다.
  - 일반 카드: `0 4px 0 #E5E5E5`
  - 금색 주 행동: `0 4px 0 #C67B00`
  - 눌림: 아래 그림자를 2px로 줄이고 요소를 2px 내린다.
- 기본 간격 축: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64px.
- 일반 카드 내부 padding: 24px. 작은 도구 카드: 12px 16px.

## 4. 전역 프레임과 헤더

```
┌──────────────────────────────────────────────────────────┐
│ Wisor 학습                                      메뉴 4개 │  60px
├──────────────────────────────────────────────────────────┤
│                         페이지 콘텐츠                     │
└──────────────────────────────────────────────────────────┘
```

- 전역 `.wrap`: 최대 1080px, 좌우 padding은 `clamp(20px, 5vw, 64px)`.
- 배우기 목록은 일곱 대가의 4+3 여정 그리드를 위해 최대 1440px까지 확장한다.
- 헤더는 흰색, 하단 1px 선, 높이 60px, sticky. 콘텐츠보다 위에 오되 과한 그림자는 없다.
- 워드마크: 1.6rem, `Wine deep`, 기준선 보정으로 2px 아래. 보조 “학습”은 0.6rem
  흐린 회색. 모바일 640px 이하에서는 보조 문구를 숨긴다.
- 메뉴: 0.98rem, 항목 간 24px. 활성 메뉴는 와인색 글자 + 아래 2px 선.
  640px 이하에서는 0.9rem, 간격 18.4px, 한 줄 가로 스크롤을 허용한다.

## 5. 화면별 레이아웃 명세

### 5.1 배우기 목록 `/learn`

```
제목

[01 버핏] → [02 그레이엄] → [03 린치] → [04 막스]
                                              ↓
[07 소로스] ← [06 그린블랫] ← [05 피셔] ←────┘
```

- 최대 프레임 1440px, 상하 padding 40px / 80px. 모바일은 40px / 64px.
- 제목 아래에서 바로 대가 여정이 시작된다. `주식 기본개념`, `대가들의 투자철학 비교` 도구는
  이 화면에 두지 않는다.
- 데스크톱은 1행 4명 + 2행 3명이며 두 번째 행은 오른쪽에서 왼쪽으로 이어진다.
  번호 `01–07`과 골드 점선 리본이 워런 버핏에서 조지 소로스로 가는 방향을 함께 설명한다.
- 900px 이하에서는 2열, 640px 이하에서도 2열을 유지한다. 카드가 화면 밖으로 잘리는
  캐러셀·fade mask·이동 화살표는 사용하지 않는다.
- 리본은 장식이 아니라 실제 학습 순서를 나타낸다. 데스크톱·태블릿·모바일의 카드 배치에
  맞는 별도 경로를 사용하고 `prefers-reduced-motion`에서는 흐름 애니메이션을 멈춘다.
- 데스크톱 리본은 07 소로스 카드 왼쪽 아래까지 연장하고 짧은 세로 줄기와 폭이 좁은
  V형이 결합된 아래 화살표로 끝낸다.
  2열 태블릿에서는 마지막 카드 오른쪽 빈 공간으로 연장해 카드와 겹치지 않게 한다.
  화살표만 1.8초 주기로 약 4–5px 떠서 아래 방향을 안내하며, reduced motion에서는 정지한다.
  공간이 빠듯한 640px 이하에는 화살표를 표시하지 않는다.

#### 대가 카드

- 데스크톱 기본 높이 320px, 행 간격 36px. 태블릿은 높이 330px, 행 간격 56px이다.
  2px 선과 4px 하단 그림자를 사용한다.
- 이미지 영역은 4:3 비율이다. 원형 초상은 데스크톱 148px, 태블릿 128px,
  모바일 96px이며 프레임 중앙에 놓는다.
- 버핏 대표 이미지는 `object-fit: cover`와 `object-position: center 6%`로 상반신을
  크롭한다. 머리 위 여백을 조금 남기고 하반신은 더 잘라 얼굴·양 어깨·손을 보존하면서
  전신 이미지의 과도한 좌우 공백을 제거하기 위한 예외다.
- 641–1400px에서는 허리 부분의 직선 크롭이 두드러지므로 버핏 원본을 카드 전체에
  `object-fit: contain`으로 유지한다. 하단 정보 패널은 투명→Surface 그라데이션으로
  하반신을 덮어, 이미지가 잘린 흔적 없이 이름 영역으로 자연스럽게 이어지게 한다.
- 버핏 대표 카드는 Gold 테두리 + Gold deep 바닥 그림자. 나머지는 회색 테두리.
- 본문 패널은 카드 하단에 고정한다. 기본 상태에는 스타일명과 대가명만 보이고,
  포인터 hover 또는 키보드 `focus-visible`에서 한 줄 소개가 위로 열린다.
- 640px 이하에서도 기본 상태에는 스타일명과 대가명만 표시하고, 포인터 hover 또는
  키보드 `focus-visible`에서 소개가 열린다. 이를 통해 7명 전체를 한 화면에 가깝게 유지한다.
- hover: 카드 3px 상승, 골드 라인으로 변경. active: 2px 하강. 이동이 과해지면 안 된다.

### 5.2 대가 경로 `/learn/masters/[slug]`

```
대가 레일 │  ┌──────────── Gold 유닛 배너 ────────────┐
           │  │ ←  우량 가치 / 워런 버핏        원칙 보기 │
  ○        │  └────────────────────────────────────────┘
  ○        │          한 줄 소개
  ○        │              ①
  ○        │          ②      장 제목
  ○        │             ③
```

- 전체 `.wrap` 1080px, 화면 상단 48px, 하단 80px.
- 넓은 화면에서 왼쪽 대가 레일은 50px 폭, 본문과 24px 간격. 뷰포트 가장자리에
  fixed로 붙이지 않는다. 화면이 넓어질수록 콘텐츠와 멀어져서는 안 된다.
- 레일 아바타: 50px 원, 세로 간격 20px. 유닛 배너 시작선보다 약 22px 아래에서 시작.
  현재 대가는 1.2배, 2px Wine soft outline, 3px offset. hover 가능한 환경에서만 최대 1.32배.
- 860px 이하에서는 레일을 배너 위 가로 스크롤 1줄로 전환하고 세로 분할선을 숨긴다.
- 유닛 배너: Gold 배경, 12px radius, 4px Gold deep 그림자, padding 14px 18px.
  뒤로가기 40px 정사각, 제목 1.35rem/800, 스타일 라벨 0.75rem/800. 480px 이하는 “원칙 보기”를 숨긴다.
- 경로 자체: 최대 460px, 5개 노드. 각 행 최소 92px, 노드 68px 원, 행의 좌우 흔들림은
  `0 / 48 / 72 / 48 / 0px`로 제한한다.
- 노드 상태:
  - 미도달: 회색 면, 숫자 `Ink faint`.
  - 완료: Gold 면 + 체크.
  - 현재: Gold 면 + Wine 4px 테두리 + `시작` 라벨.
- 장 제목은 0.9rem/700, 장 종류 라벨은 0.7rem 흐린 회색.

### 5.3 챕터 학습 `/learn/masters/[slug]/[chapter]`

```
             ← 대가 목차
             메타
             챕터 제목 / 와인색 리드 / 질문
             ──────────────────────────────
             ━━━━━━━  · · · ·

    캐릭터  │  읽기 본문 또는 문항 카드
             ──────────────────────────────
                         1 / 5        계속
             ──────────────────────────────
             기준일 고지
```

- 넓은 화면 프레임: 최대 1080px.
- 챕터의 실제 내용 구조: 왼쪽 캐릭터 전용 열 152px + 분리 간격 24px + 본문·문항 열 최대 720px.
  구현 값은 `--chapter-gutter: 176px`이며, 첫 grid 열은 `176 - 24 = 152px`이다.
- 제목·리드·질문·진행 바·문항·하단 이동 영역은 모두 본문 시작선(캐릭터 열 뒤)에 맞춘다.
- 읽기 문단은 최대 40em, 1.03rem/1.9. 720px 문항 열을 가득 채워 문장 폭을 키우지 않는다.
- 상단 질문에서 구분선·진행 바까지의 여백은 기본 rule보다 압축한다.
  챕터 내부 rule은 상하 24px(`1.5rem`), 질문 하단은 20px(`1.25rem`).
- 진행 막대: 5px 높이, 간격 3px, 현재 막대는 9px + Wine 2px 테두리. 하단 여백 24px.
- 본문/문항 종료 후 하단 이동 영역은 margin-top 20px, padding-top 12px. 고지문은 그 뒤
  margin-top 16px, padding-top 12px. 이 두 구간을 다시 크게 벌리지 않는다.
- 860px 이하: 캐릭터 전용 열을 없애고 단일 열. 캐릭터는 본문 위 중앙, 높이 110px.

## 6. 캐릭터 에셋과 배치 규칙

### 6.1 파일 규격

| 종류 | 파일 | 원본 규격 | 사용처 |
| --- | --- | --- | --- |
| 대표 전신 | `main.png` | 842×1264, RGB | 배우기 목록의 버핏 대표 카드 |
| 정지 전신 | `stand.webp` | 506×720, RGBA | 대가 경로, reduced motion 대체 |
| 안내 | `guide.webp` | 226×360, RGBA, 30 frames | 읽기 단계 |
| 정답/응원 | `great.webp`, `proud.webp`, `aha.webp` | 높이 360, RGBA | 정답·요약·기록 완료 |
| 아쉬움 | `nope.webp` | 166×360, RGBA | 오답 상태 |

- 캐릭터 애니메이션은 **반드시 알파 채널이 있는 WebP**를 사용한다. 흰 사각형 배경이
  보이는 GIF·RGB 애니메이션은 허용하지 않는다.
- 현재 WebP는 프레임당 80~90ms다. 기존 60~70ms GIF보다 약 33% 느린 템포이며,
  5개 합계는 약 1.45MB다.
- 모든 애니메이션은 높이 360px 기준으로 잘라 발 위치가 일관된다. 폭을 고정하거나
  `object-fit: cover`로 자르지 않는다.
- `prefers-reduced-motion: reduce`에서는 mood와 상관없이 `stand.webp` 정지 이미지를 쓴다.

### 6.2 위치와 방향

- 챕터 화면: 데스크톱에서 캐릭터는 본문 **밖이 아니라 전체 콘텐츠 프레임 안의 왼쪽 거터**에 둔다.
  버핏의 오른손이 본문·선택지를 향하도록 한다. 내용 열 위에 absolute로 얹지 않는다.
- 모바일: 위 중앙으로 옮기고 110px으로 축소한다. 텍스트와 문항 앞에 오되 방해하지 않는다.
- 대가 경로: 버핏은 `scaleX(-1)`로 반전한 정지 전신을 노드 왼쪽에 둔다. 노드마다 추적하지 않고
  **1·2장 / 3장 / 4·5장** 세 구간에서만 이동한다. 이는 캐릭터가 UI를 쫓아다니는 느낌을 막기 위함이다.
- 대가 경로 캐릭터 크기: 데스크톱 190px, 1100px 이하 150px, 640px 이하 124px.
- 캐릭터에 hover 이동이나 상시 부유 애니메이션을 주지 않는다. 캐릭터가 아니라 CTA만 행동을 유도한다.

### 6.3 CTA와 캐릭터의 관계

- 경로 CTA는 캐릭터 위의 작은 Wine outline 말풍선이다. 최소 높이 34px, 2px Wine 선,
  3px Wine line 그림자, 아래쪽 10px 꼬리를 사용한다.
- 이어서 하기 CTA만 reduced-motion이 아닐 때 1.8초 주기로 최대 3px 위아래 움직인다.
- hover/focus 시 CTA는 2px 상승, Wine soft 배경, 그림자 5px. 캐릭터는 움직이지 않는다.
- 1100px 이하에서는 캐릭터 위 CTA를 숨기고 현재 노드 위의 같은 기능 CTA로 전환한다.

## 7. 학습 컴포넌트 상태 규칙

| 컴포넌트 | 기본 | hover/focus | active / 완료 / 오류 |
| --- | --- | --- | --- |
| Gold 버튼 | Gold + 4px Gold deep | Gold deep | 2px 하강·그림자 2px |
| Quiet 버튼 | 흰 면 + 회색 2px 선 | Wine soft + Wine line | 2px 하강 |
| 선택지 | 흰 면 + 1px 회색 선 | Wine line | 정답 Wine/Wine soft, 오답 Ochre/Ochre soft |
| 대가 카드 | 회색 2px 선·4px 그림자 | 3px 상승·Gold line | 2px 하강 |
| 현재 경로 노드 | Gold + Wine 4px 선 | 링크 접근성 유지 | 현재 위치는 라벨로도 표시 |
| 비활성 버튼 | 회색 면·흐린 글자 | 반응 없음 | 클릭 불가 |

`focus-visible`은 모든 화면에서 Wine 2px outline + 2px offset을 유지한다.

## 8. 반응형 기준

| 구간 | 규칙 |
| --- | --- |
| 861px 이상 | 대가 세로 레일, 챕터 캐릭터 왼쪽 거터, 2열 학습 도구 |
| 641–860px | 대가 레일은 가로 스크롤, 챕터는 단일 열 + 상단 중앙 캐릭터 |
| 481–640px | 헤더 보조문구 제거, 140px 높이의 대가 그리드 2열·소개 hover, 경로 캐릭터 124px |
| 401–480px | 140px 카드 2열을 유지하고 유닛 배너의 보조 링크를 숨김 |
| 400px 이하 | 카드 136px·행 간격 10px로 압축해 375×812에서도 일곱 대가를 노출 |

모든 구간에서 문서 자체의 가로 overflow는 0이어야 한다. 대가 목록은 별도의 가로
스크롤 없이 전원을 보여 주며, 헤더 메뉴의 의도된 내부 스크롤만 허용한다.

## 9. 다른 메뉴에 적용하는 방법

### 그대로 재사용할 것

- 흰 바탕 + Gold 주 행동 + Wine 현재 상태의 의미 체계
- 12px radius, 3~5px 하단 단색 그림자, 눌림 2px
- Pretendard 산세리프 활자 스케일과 흐린 메타 라벨
- 한 화면 한 주 행동, 순서가 있는 작업에는 노드·진행 막대
- 넓은 화면에서 별도 캐릭터 거터를 두고, 모바일에서 상단 중앙으로 전환하는 방식

### 화면 성격에 맞춰 바꿔도 되는 것

- 콘텐츠 프레임 폭: 비교·데이터 표는 1080px 이상, 읽기 중심 화면은 720px 칼럼 중심.
- 캐릭터 종류·행동: 해당 메뉴의 행동과 연결되는 포즈·mood만 새로 만든다.
- 노드 수와 진행 단위: 실제 단계 수를 반영한다. 장식용 5단계 복제 금지.
- 카드 크기: 콘텐츠의 이미지 비율과 정보량에 맞춰 조정한다.

### 하지 말 것

- 금색을 섹션 배경, 배지, 아이콘, 버튼에 동시에 과도하게 쓰지 않는다.
- 버건디를 경고색으로 쓰지 않는다. 현재 위치·정답·강조라는 학습 의미를 유지한다.
- 학습 경로·챕터 캐릭터에 불투명 흰 사각 배경을 붙이거나 `cover`로 팔다리를 자르지 않는다.
  배우기 목록의 버핏 상반신 크롭은 카드 비례를 맞추기 위해 승인된 예외다.
- 캐릭터를 뷰포트 끝에 fixed로 띄우거나 텍스트·선택지와 겹치게 하지 않는다.
- 넓은 화면에서 모든 선과 진행 바를 무조건 전체 칼럼 끝까지 길게 늘려 리듬을 흐리지 않는다.
- 데스크톱 레이아웃을 단순 축소해 모바일에 가져가지 않는다. 레일과 캐릭터는 구조를 바꾼다.

## 10. 구현·검수 체크리스트

### 구현 전

- [ ] 이 화면의 단 하나의 주 행동이 Gold 버튼 또는 Gold 노드로 읽히는가?
- [ ] Wine은 현재·선택·정답에만 쓰였는가?
- [ ] 캐릭터의 손 방향과 시선이 콘텐츠 또는 다음 행동을 향하는가?
- [ ] 캐릭터 파일은 투명 RGBA WebP 또는 PNG인가?
- [ ] 텍스트는 한글 단어 단위로 자연스럽게 줄바뀌는가?

### 구현 후

- [ ] 1920px, 1280px, 860px, 640px, 390px에서 가로 overflow가 없는가?
- [ ] 캐릭터·말풍선·현재 노드가 서로 겹치지 않는가?
- [ ] 카드 hover와 버튼 active가 2~3px의 촉감만 주며 레이아웃을 흔들지 않는가?
- [ ] `prefers-reduced-motion`에서 반복 애니메이션이 멈추고 정지 캐릭터로 바뀌는가?
- [ ] 진행 상태가 색, 아이콘/테두리, 텍스트 중 둘 이상으로 전달되는가?
- [ ] 작은 화면에서 일곱 대가가 누락되지 않고 2열 순서로 이어지는가?
