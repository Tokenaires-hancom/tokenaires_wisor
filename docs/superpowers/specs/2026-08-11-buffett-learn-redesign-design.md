## 1. 색

듀오링고가 초록을 쓰는 자리를 전부 골드가 받는다. 버건디는 포인트에만 쓴다.
배경은 듀오링고와 같은 순백이다.

```
--gold:      #FFA000   메인 — 듀오링고 --color-owl 자리
--gold-deep: #C67B00   버튼 아래 4px 그림자 — --color-tree-frog 자리
--gold-soft: #FFF4E0   연한 면
--gold-line: #FFD08A   테두리

--wine:      #C2183C   포인트
--wine-deep: #92102C   눌림
--wine-soft: #FCE9ED
--wine-line: #EFA9B7
```

**골드는 흰 글씨를 얹어도 된다.** `#FFA000`의 흰 글씨 대비는 2.05:1로,
듀오링고 초록 `#58CC02`(2.06:1)와 사실상 같다. 레퍼런스가 실제로 굴리는
조건과 동일하므로 갈색 글씨로 우회하지 않는다. 대신 듀오링고와 같은 조건을
따라간다 — 골드 위 글자는 **16px 이상, 굵기 700 이상**으로만 쓴다. 작은
설명 문구를 골드 위에 올리지 않는다.

후보 중 `#FFB800`은 대비가 1.72:1까지 떨어져 탈락했다. 흰 배경에서 가장자리가
뜨는 문제도 있었다.

| 골드 | 버건디 |
|---|---|
| 주 버튼 배경 + 흰 글씨 | 현재 노드 테두리 |
| 유닛 배너 배경 | 스타일 뱃지 배경 |
| 완료 노드 채움 | 포커스 링 |
| 진행바 채움 | 강조 텍스트·링크 |
| 카드 상단 배경 | 정답 표시 |

**뉴트럴도 듀오링고 값으로 맞춘다.** 기존 회보라 계열(`#f6f5f8` 등)을 버린다.

```
--paper:        #FFFFFF   --color-snow
--surface:      #FFFFFF
--surface-sunk: #F7F7F7   --color-polar
--ink:          #4B4B4B   --color-eel
--ink-soft:     #777777   --color-wolf
--ink-faint:    #AFAFAF   --color-hare
--line:         #E5E5E5   --color-swan
--line-strong:  #CFCFCF   --color-cloud
```

기존 `--ochre*`(미충족 황토)는 그대로 둔다. 골드와 색상환에서 가깝지만
채도·명도가 충분히 낮아 골드 채움과 구분된다. 기준 막대는 이번 범위 밖이다.

`--plum` 계열은 CSS 66곳, TSX 6곳에 있다. 이름을 일괄 치환하면 스크리너·비교·
종목 상세도 새 색을 자동으로 입는다. 레이아웃은 건드리지 않는다.

**듀오링고식 입체 버튼.** `.btn`에 `box-shadow: 0 4px 0 var(--gold-deep)`을 주고
`:active`에서 `transform: translateY(2px)`와 그림자 2px으로 눌리게 한다.
듀오링고 버튼의 촉감이 여기서 나온다. `prefers-reduced-motion`에서도
그림자는 유지한다 — 움직임이 아니라 형태다.

## 2. 활자

`--serif`(고운바탕) 변수를 없앤다. 호출부는 CSS 7곳, TSX 3곳.

- 전부 `--sans`로 교체
- 듀오링고식 무게 대비: `.thesis` `.chapter-title` `h2.section`의
  `font-weight: 400` → `800`
- `.thesis`의 `max-width: 26ch`는 명조 "0" 폭(0.54em) 기준으로 계산된 값이다.
  산세리프는 "0"이 더 넓으므로 `20ch`으로 줄인다.
- `.chapter-lede` `.lens-note`의 `font-family` 선언은 삭제(본문 폰트 상속)

| 깨닭음.gif | `aha.gif` | 폭 320 |

`워랜 메인.png`는 배경 일러스트(분홍 바탕 + 파란 블롭)가 골드 팔레트와 충돌해
쓰지 않는다. `pic.webp`(실사 사진), `워랜시트.png`(6포즈), `시행착오/`도 이번
범위 밖이다.

**배경 제거 방법.** 소메인의 알파 채널은 전부 255다 — 투명이 아니라 흰
배경이다. 흰색을 일괄 제거하면 셔츠 깃과 소매까지 뚫린다. 이미지 가장자리에서
시작하는 flood fill로 **바깥쪽에 연결된 흰 픽셀만** 지운다. Python PIL과
numpy를 쓴다.

가공 스크립트는 저장소에 남기지 않는다. 결과 파일만 커밋한다.

## 4. `/learn` — 대가 선택

세로 카드 3열 그리드. 카드 하나가 대가 한 명.

```
┌──────────────┐
│  골드 배경    │  높이 140px, 캐릭터 전신이 아래에 걸쳐 서 있다
│    (캐릭터)   │  object-fit: contain / object-position: bottom
├──────────────┤
│ [우량 가치]   │  버건디 pill
│ 워런 버핏     │  16px / 800
│ 오래 돈 버는… │  12px / --ink-soft, 두 줄
└──────────────┘
```

**빈 슬롯 여섯.** 상단은 골드 대신 `--surface-sunk`, 캐릭터 자리에 회색 사람
아이콘. 테두리는 점선. 이름 아래 한 줄은 "캐릭터 준비 중". 링크는 살려 둔다 —
글은 이미 다 있다. `opacity: 0.6`.

캐릭터 유무는 `masters.ts`에 필드를 새로 만들지 않고, 파일 존재로 갈리는
상수 배열 하나(`CHARACTER_READY = ["buffett"]`)로 판정한다. 대가가 늘어날 때
줄 하나 추가하면 된다.

## 5. `/learn/masters/buffett` — 노드 패스

기존 `MasterPath`의 세로 목록을 지그재그 노드로 바꾼다.

**유닛 배너 (상단).** 골드 배경 라운드 박스. 좌측 `←` 배우기 목록,
"버핏 · N장 / 5", 장 제목. 우측에 「원칙 보기」 버튼 — 지금 페이지 아래에 있는
`master-tips`의 철학 원칙 `<details>`를 여는 앵커.

**노드 5개.** 원형 지름 64px, 세로로 쌓되 좌우 오프셋 `0 / +48 / +72 / +48 / 0`
px으로 구불구불하게. 상태 셋:

| 상태 | 모양 |
|---|---|
| 완료 | 골드 채움 + 흰 체크 + `0 4px 0 --gold-deep` |
| 현재 | 골드 채움 + 버건디 4px 테두리 + 위에 "시작" 말풍선 |
| 미완 | `--line` 회색 채움 + `0 4px 0 --line-strong` |

색만으로 구분하지 않는다 — 완료는 체크 표시, 현재는 테두리와 말풍선이 함께
붙는다.

**진행한 데까지만 색이 칠해진다.** 듀오링고 캡쳐에서 확인한 규칙이다. 아직
도달하지 않은 구간은 노드뿐 아니라 그 구간에 딸린 장식까지 전부 회색이다.
우리 화면에서는 미완 노드 옆 캐릭터에 `filter: grayscale(1)`을 건다.

**장 사이 구분.** 듀오링고는 유닛 사이에 가로선 + 가운데 다음 유닛 제목을
넣고, 그 아래 "여기로 건너뛸까요?" 말풍선과 건너뛰기 버튼을 붙인다.
우리는 5장이 한 흐름이라 유닛이 하나뿐이므로 **구분선과 건너뛰기 버튼은 넣지
않는다.** 대신 배너의 장 제목이 현재 장에 따라 바뀐다.

건너뛰기를 넣지 않는 이유는 화면 수가 적어서만이 아니다. 각 장은 앞 장의
판단 기준 위에 쌓이므로 건너뛰면 뒤 문항의 근거가 사라진다.

**캐릭터.** 패스 오른쪽에 `stand.webp`가 서 있다. 애니메이션 없음.

**왼쪽 대가 이동 레일은 유지한다.** 듀오링고에는 없지만 일곱 대가를 오가는
경로가 이것뿐이다.

## 6. 챕터 페이지 — 캐릭터 동반

`ChapterExercises`는 이미 단계 상태를 전부 들고 있다. 오른쪽에 sticky 캐릭터
슬롯을 붙이고 상태에 따라 GIF를 바꾼다.

| 단계 | GIF |
|---|---|
| 본문 읽기 (`read`) | guide |
| 채점 문항, 정답 | great |
| 채점 문항, 오답 | nope |
| 써보기·기록 제출 뒤 | proud |
| 요약 (`summary`) | aha |
| 그 외 (미제출 상태) | guide |

정답/오답 판정은 이미 `isCorrect(exercise.answers, picks[i])`가 한다. 새 로직이
아니라 기존 판정을 한 번 더 읽는 것이다.

`prefers-reduced-motion: reduce`면 GIF 대신 `stand.webp` 정지 이미지를 쓴다.
움직임을 꺼 달라고 한 사용자에게 반복 애니메이션을 보이지 않는다.

**모바일 (≤640px).** 캐릭터를 본문 위로 올리고 폭 96px로 줄인다.

## 7. 만들지 않는 것

하트·젬·스트릭 카운터. 듀오링고 우측 레일의 핵심이지만 `lib/store.ts`에는
`lessonsDone`과 퀴즈 기록밖에 없다. 경제 시스템을 새로 만드는 일이고 이번
"약간의 기능 수정" 범위를 넘는다.

리더보드, 프로필, 로그인도 같은 이유로 제외한다.

## 8. 검증

1. `npm install && npm run dev` — **변경 전에** 먼저 띄우고 `/learn`,
   `/learn/masters/buffett`, `/learn/masters/graham` 스크린샷을 남긴다.
   비교 기준선이다.
2. 각 단계 뒤 같은 세 화면을 다시 찍어 비교한다. 특히 `graham`처럼
   캐릭터가 없는 대가의 화면이 깨지지 않는지 본다.
3. `npm run build` 통과
4. `npx vitest run` — 기존 29개 웹 테스트 통과
5. 콘솔 에러 없음 (`read_console_messages`)
