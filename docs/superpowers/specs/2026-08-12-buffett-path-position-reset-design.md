# 버핏 경로 캐릭터 위치·처음부터 학습하기 설계

## 목표

- 학습 진행 단계가 바뀌어도 버핏 캐릭터가 노란 현재 노드와 겹치지 않는다.
- 캐릭터가 항상 현재 학습 단계를 안내하는 존재로 읽힌다.
- 사용자가 해당 대가의 학습만 처음부터 다시 시작할 수 있다.

## 캐릭터 배치

- 캐릭터는 장마다 이동하지 않고 다음 세 구간의 고정 앵커만 사용한다.
  - 현재 장이 1·2장: 1번과 2번 노드 사이 왼쪽
  - 현재 장이 3장: 3번 노드 왼쪽
  - 현재 장이 4·5장 또는 전체 완료: 4번과 5번 노드 사이 왼쪽
- 첫 구간 캐릭터의 상단은 모든 화면 폭에서 소개 문장 `오랫동안 돈을 잘 버는
  기업을 합리적인 가격에 찾습니다.` 아래에 있어야 한다.
- 각 구간에서 캐릭터는 인접한 두 노드와 모두 분리되어야 한다. 캐릭터 오른쪽과
  가장 가까운 노드 왼쪽 사이의 최소 안전 간격은 다음과 같다.
  - 데스크톱·태블릿: 20px
  - 모바일: 14px
- 캐릭터와 CTA 말풍선은 서로 겹치지 않으며 최소 5px 떨어진다.
- 1·2장과 4·5장 구간에서는 두 노드 사이의 고정 세로 위치를 사용한다. 3장
  구간에서는 3번 노드의 세로 중심을 기준으로 배치한다.
- 1·2장 앵커는 기본 앵커보다 아래 30px, 왼쪽 20px 보정한다. 데스크톱에서는
  캐릭터 쪽 CTA 말풍선이 소개 문장과 겹치지 않도록 아래 12px을 추가한다.
  이 보정으로 캐릭터와 CTA 말풍선 모두 소개 문장 아래에 놓인다.
- 3장 앵커는 기본 앵커보다 아래 66px, 왼쪽 20px 보정한다. 캐릭터 발끝은
  4번 노드 세로 중앙을 기준으로 둔다. 2번 완료 노드와
  시각적으로 분리하고 3번 현재 노드의 안내자로 읽히게 한다.
- 4·5장 앵커는 현 위치를 유지하며 보정하지 않는다.
- 크기는 기존 선명도 기준을 유지한다.
  - 데스크톱: 190px
  - 1100px 이하: 150px
  - 640px 이하: 124px
- 버핏 캐릭터 자체에는 애니메이션을 적용하지 않는다.
- `n장부터 이어서 하기` 말풍선의 기존 모션과 접근성 설정은 유지한다.

## 처음부터 학습하기

- 진도가 한 장 이상 있을 때만 경로 아래에 `처음부터 학습하기` 보조 버튼을 표시한다.
- 주요 CTA와 경쟁하지 않도록 작은 텍스트형 보조 버튼으로 표현한다.
- 클릭하면 확인창에 다음 내용을 명시한다.
  - 해당 대가의 완료 상태와 퀴즈 결과가 초기화됨
  - 기록형 답변은 유지됨
- 확인한 경우에만 다음 데이터를 제거한다.
  - `lessonsDone`에서 `master:<masterId>:` 접두사를 가진 항목
  - `quizResults`에서 같은 접두사를 가진 항목
- 관심종목, 학습노트, 다른 대가의 진도, 기록형 답변은 변경하지 않는다.
- 초기화 직후 페이지를 새로고침하지 않고 1번 노드를 현재 상태로 다시 표시한다.

## 구현 경계

- `MasterPath.tsx`: 현재 장을 세 구간 앵커로 변환, 초기화 버튼과 상태 갱신
- `lib/store.ts`: 해당 대가의 진도·퀴즈 결과만 초기화하는 함수
- `globals.css`: 캐릭터 안전 간격과 초기화 버튼 스타일
- 커리큘럼 콘텐츠와 퀴즈 문항은 변경하지 않는다.

## 검증

- 진도 0~5장 각각에서 올바른 세 구간 앵커를 사용하는지 확인한다.
- 1·2장 구간에서 캐릭터가 소개 문장 아래에 있고 두 노드 모두와 겹치지 않는지 확인한다.
- 1·2장 구간에서 CTA 말풍선도 소개 문장 아래에 있고 캐릭터와 겹치지 않는지 확인한다.
- 3장과 4·5장 구간에서도 인접 노드 및 CTA 말풍선과 겹치지 않는지 확인한다.
- 1920, 1180, 1024, 900, 640, 510, 360px에서 위치와 가로 오버플로를 확인한다.
- 초기화 시 현재 대가의 진도·퀴즈만 사라지고 기록형 답변과 다른 대가 진도는 유지되는 단위 테스트를 추가한다.
- 기존 전체 테스트와 레이아웃 검사를 통과한다.
