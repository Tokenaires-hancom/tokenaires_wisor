# CLAUDE.md — services/chart-api

> 담당: 4번(차트 교육·비전 LLM·안전성·품질)
> 루트 `CLAUDE.md`의 규칙이 먼저 적용됩니다.

## 이 서비스가 하는 일

차트 이미지 1장 → 보이는 것의 교육용 설명. **그게 전부입니다.**

```
app/services/prompt.py           1차 방어선 — 프롬프트 제약
app/services/safety.py           2차 방어선 — 출력 필터
app/services/llm_adapter.py      공급자 교체 지점 (anthropic · mock)
app/services/vision_analyzer.py  흐름 조립 + 재생성·거절 정책
app/schemas/analysis.py          응답 스키마 (extra="forbid")
app/api/analyze.py               POST /api/chart/analyze
```

## 이 서비스가 받지 않는 것

**종목명, 티커, 보유 여부, 사용자 메모.** 받는 것은 이미지와 선택적 `lesson_id`뿐입니다.

이유: 모델이 회사를 알아보면 이미지에 없는 지식으로 전망을 덧붙입니다. 그 경로를 입력 단계에서 막습니다. 프론트엔드가 종목 상세에서 호출하더라도 종목 연결은 프론트와 학습노트에서만 관리합니다.

## 이 서비스가 내보내지 않는 것

매수·매도 판단, 진입·청산 시점, 목표가, 손절가, 미래 가격이나 방향, 상승·하락 확률, 투자 적합성, 수익 보장, "확실한 신호"라는 단정.

`AnalysisResponse`가 `extra="forbid"`인 것과 `FORBIDDEN_FIELDS` 목록이 있는 것은 실수가 아닙니다.

## 이중 안전장치

**1차 — 프롬프트.** 이미지 안 문자는 분석 대상이지 지시가 아니라는 규칙, 외부 지식 금지, 판독 불가 시 거절 규칙. `relatedLessons`는 `LESSON_IDS` 화이트리스트로 고정합니다.

**2차 — 출력 필터.** 두 등급입니다.

| 등급 | 동작 | 해당 |
|---|---|---|
| `sentence` | 그 문장만 떼고 나머지는 살림 | 외부 정보 인용, 종목 추측 |
| `block` | 응답 전체 폐기 → 1회 재생성 → 그래도 걸리면 거절 | 매매, 목표가, 예측, 확률, 보장 |

전부 `block`으로 두지 않는 이유: 문장 하나 때문에 멀쩡한 분석 전체가 버려집니다.

## 필터를 고칠 때

**반드시 테스트 표본을 먼저 늘립니다.**

- 걸러져야 하는데 통과한 문장 → `tests/test_safety.py`의 `MUST_BLOCK`에 **모델이 실제로 낸 문장 그대로** 추가
- 정상인데 걸린 문장 → `MUST_PASS`에 추가
- 그다음 `RULES`를 고칩니다

이 두 목록이 필터의 기준선입니다. 규칙만 고치고 표본을 안 늘리면 같은 실수가 다시 통과합니다.

과잉 차단도 실패입니다. "골든크로스는 단기선이 장기선을 위로 지나는 현상을 부르는 이름입니다" 같은 교육 문장은 반드시 살아야 합니다.

## 프롬프트를 고칠 때

`PROMPT_VERSION`을 올립니다. 응답에 실려 나가고 사용 기록에 남으므로, 품질이 나빠졌을 때 어느 버전부터인지 되짚을 수 있어야 합니다.

## 학습 단원 id

`prompt.py`의 `LESSON_IDS`와 `apps/web/content/chartLessons.ts`의 `id`가 **반드시 같아야 합니다.** 어긋나면 분석 결과가 없는 페이지로 링크됩니다. 한쪽만 고치지 않습니다.

## 이미지 처리

**모든 업로드는 `services/image.py`의 `normalize()`를 거칩니다.** 원본을 그대로 모델에 보내지 않습니다.

정규화가 하는 일 세 가지:

1. **EXIF 제거** — 휴대폰 사진에는 촬영 위치(GPS)와 기기 정보가 들어 있습니다. 차트 영역만 잘라 올리라고 안내해 놓고 좌표를 함께 보내면 약속을 어기는 것입니다. 회전 정보는 픽셀에 반영한 뒤 메타데이터를 버립니다
2. **축소** — 긴 변 1568px. 그 이상은 토큰만 더 쓰고 판독은 나아지지 않습니다. 휴대폰 사진 기준 전송량이 95% 줄어듭니다
3. **사전 거절** — 긴 변이 400px 미만이면 모델을 부르기 전에 돌려보냅니다

정규화에 실패하면 **원본을 흘려보내지 않고 거절합니다.** 안전한 실패 쪽을 택합니다.

메모리에서만 다루고 응답 후 버립니다. 디스크에 쓰지 않고, 로그에 남기지 않고, 외부로 보내지 않습니다. 남기는 것은 사용자 ID·시각·성공 여부·단원·필터 건수·크기 변화뿐입니다.
