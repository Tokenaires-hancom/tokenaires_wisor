# 투자 스타일 커리큘럼 2단계 — 구현 기록

작성일 2026-08-06 · 기준 문서 `investment-styles-curriculum (1).md`

## 범위

- 피셔·그린블랫·막스·소로스 프로필과 각 5장 커리큘럼
- 피셔·막스·소로스의 정성 자가진단
- 그린블랫의 자본수익률·이익수익률 상대 순위 모델
- 일곱 스타일의 전제·탐색·검증·처분·실패 횡단 비교
- 자본 구조·기질·역량의 최종 기록 문항

## 모델 경계

버핏·그레이엄·린치는 종목 하나의 재무지표를 절대 기준과 비교한다. 그린블랫은 종목
하나만으로 판정할 수 없으므로 전체 유니버스에서 두 지표의 순위를 계산하고 합산한다.
피셔·막스·소로스는 현재 데이터로 핵심 질문을 측정할 수 없어 점수를 만들지 않는다.

그린블랫 1.0:

1. 5년 평균 자본수익률을 내림차순으로 순위 매긴다.
2. EBIT / 기업가치를 내림차순으로 순위 매긴다.
3. 두 순위를 합산하고 낮은 합부터 종합 순위를 매긴다.
4. 합산값이 같으면 같은 종합 순위를 부여한다.
5. 두 지표 중 하나라도 없으면 정보 부족으로 둔다.

## 화면 구조

- 홈과 배우기는 일곱 스타일을 모두 보여주고 `점수 모델`과 `자가진단`을 구분한다.
- 정성형 대가 상세는 종목 링크 대신 직접 확인할 다섯 항목과 첫 장 링크를 보여준다.
- `/learn/compare`는 일곱 행과 다섯 공통 열을 맞춘 표, 처분 조건 표, 최종 기록을 제공한다.
- 스크리너는 점수 모델이 있는 네 스타일만 정적 생성한다.

## 검증 기준

- 웹 콘텐츠 검사와 단위 테스트
- 데이터 파이프라인 순위·결측·안전 문구 테스트
- 7명×5장 정적 경로와 비교·스크리너 경로 빌드
- 재무 원천과 커리큘럼 본문의 클라이언트 번들 미포함
